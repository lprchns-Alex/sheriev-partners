# Каталог интерфейса v.7.final

Открывается по адресу `https://lprchns-alex.github.io/sheriev-partners/v.7.final/ui-kit/`.

Это статический каталог в духе Storybook. Он загружает действующие `style.css`, `client.css`, `audience.css` и `results.css`; отдельной сборки нет. Локальный `ui-kit.css` оформляет только страницу каталога и размеры её образцов.

При изменении действующего компонента сначала обновите CSS сайта, затем проверьте соответствующий образец здесь. Новый образец добавляется как раздел в `index.html` со ссылкой на исходный CSS. `ui-kit.js` управляет переключением светлого и тёмного фона, подсветкой раздела в навигации и демонстрационным сообщением формы. Форма не отправляет данные.
