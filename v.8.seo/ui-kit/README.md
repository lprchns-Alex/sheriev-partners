# Каталог интерфейса v.8.seo

- Публичный адрес: https://lprchns-alex.github.io/sheriev-partners/v.8.seo/ui-kit/
- Локальный адрес: http://127.0.0.1:4392/ui-kit/

Статический каталог в духе Storybook, без отдельной сборки. Подключает действующие стили сайта, включая фирменную символику и отзывы новой главной. `ui-kit.css` оформляет только каталог и размеры образцов; клиентские страницы не изменяются.

## Разделы

Цвета, типографика, кнопки и ссылки, навигационные строки, публикации, результаты, цены, карточка адвоката, форма, выбранные логотипы, состояния элементов, фильтры и поиск, раскрывающиеся блоки, отзывы. В разделе «Страницы и блоки» доступны 36 страниц в iframe с шириной 375, 768, 1440 px или по контейнеру. Кнопки сценариев показывают начало страницы, закреплённую навигацию, мобильное меню, форму и подвал.

Поиск слева фильтрует разделы. Наведение и фокус также показаны статически для сравнения. Состояния нажатия, недоступности, отправки и ответы формы отмечены как эскизы: они существуют только в каталоге. Демонстрационная форма не отправляет данные. Каталог закрыт от индексации.

## Обновление

При изменении компонента сначала обновите общий CSS сайта, затем проверьте образец здесь. Для нового компонента добавьте раздел и его поисковые слова в `data-story-title`, ссылку в навигацию и источник стилей. Для новой страницы добавьте option в `#kit-page-select` и обновите счётчик страниц в тексте каталога. Просмотр в iframe использует настоящие страницы, поэтому их изменения видны сразу.

`ui-kit.js` управляет поиском, демонстрационными состояниями, фильтрами и просмотром страниц; внешних запросов для отправки форм в нём нет.
