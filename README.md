## Локальная работа

Откройте папку репозитория в VS Code. Сборка и установка зависимостей не требуются.

Для локального просмотра:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/ в браузере. Стартовая страница — `index.html`.

## Публикация

GitHub Pages публикует корень ветки `main`. Изменения появляются на сайте после отправки коммита и успешного завершения публикации.

## Статус прототипов

Формы демонстрационные: обращения не отправляются. Контактные ссылки ведут на телефон и публичные страницы коллегии.

Материалы коллегии используются для демонстрации дизайна. Этот репозиторий не предоставляет отдельной лицензии на фотографии, тексты или фирменные материалы.
